# Minimalism Expo 공통 템플릿 설계

## 목표

앱별 GitHub 레포지토리를 독립적으로 생성할 수 있도록, 작업 시점의 최신 안정 Expo SDK를 사용하는 공통 시작 템플릿을 만든다. 템플릿은 앱 기능을 포함하지 않고 흑색–회색–백색 디자인 시스템, 공통 UI, 라우팅, 로컬 저장 경계를 제공한다.

## 범위

포함한다.

- Expo Router 기반 TypeScript 프로젝트
- 작업 시점의 공식 최신 안정 Expo SDK와 호환 의존성
- React Native Paper MD3 기반 흑백 테마
- 색상·간격·타이포그래피 토큰
- `AppScreen`, `AppText`, 버튼, 카드, 입력, 빈 상태 등 공통 UI
- 디자인 시스템을 확인하는 템플릿 쇼케이스 화면
- 기기 내부 저장소를 연결할 수 있는 타입과 인터페이스
- README, EAS 설정, 테스트 기본 구조

포함하지 않는다.

- 카메라·위치·연락처·센서·알림 등 기능별 네이티브 모듈
- Supabase, 서버 API, 외부 DB
- 특정 앱의 업무 도메인과 화면
- 커스텀 폰트 파일

## 선택한 접근

세 가지 접근 중 로컬 퍼스트 공통 템플릿을 선택한다.

1. 라우터와 테마만 포함하는 최소 템플릿은 가볍지만 앱마다 UI 기반을 반복 구현해야 한다.
2. 테마·공통 UI·저장소 경계·쇼케이스를 포함하는 템플릿은 반복 작업을 줄이면서 기능별 의존성을 앱에 남길 수 있다.
3. 별도 디자인 시스템 패키지는 여러 레포지토리의 버전과 배포를 관리해야 하므로 현재의 경량화 목적에 맞지 않는다.

## 기술 기준

- Expo SDK는 고정 숫자가 아니라 작업 시작 시점의 공식 최신 안정 버전을 사용한다.
- `beta`, `preview`, `canary` 등 사전 릴리스는 사용하지 않는다.
- Expo Router를 파일 기반 라우터로 사용한다.
- `src/app`에는 라우트 파일만 둔다.
- 화면 본문은 `src/screens`, 재사용 UI는 `src/components`에 둔다.
- React Native Paper의 MD3 테마를 프로젝트 테마로 감싼다.
- 네이티브 모듈은 필요한 앱 레포지토리에서 `npx expo install`로 추가한다.
- 기본 템플릿에는 기능별 네이티브 권한을 선언하지 않는다.
- 데이터 저장 구현은 템플릿에 특정 저장 패키지를 강제하지 않고 인터페이스만 제공한다.

## 디렉터리 구조

```text
minimalism-template/
├─ assets/
├─ src/
│  ├─ app/
│  │  ├─ _layout.tsx
│  │  └─ index.tsx
│  ├─ components/
│  │  └─ ui/
│  ├─ screens/
│  │  └─ template-showcase/
│  ├─ theme/
│  ├─ storage/
│  ├─ hooks/
│  └─ utils/
├─ app.json
├─ eas.json
├─ package.json
├─ tsconfig.json
├─ README.md
└─ AGENTS.md
```

## 디자인 시스템

색상 토큰은 모두 무채색으로 정의한다.

```text
ink: #111111
charcoal: #2B2B2B
graphite: #666666
mist: #D9D9D9
paper: #F6F6F6
white: #FFFFFF
```

간격은 `4, 8, 12, 16, 24, 32`, 모서리 반경은 `8, 12, 16`을 기본값으로 사용한다. 폰트는 시스템 폰트를 사용하고, 제목·본문·보조 텍스트의 크기와 굵기를 토큰으로 관리한다.

공통 UI는 얇은 테두리, 넉넉한 여백, 제한된 색상 대비를 사용해 앱 기능을 방해하지 않는 방향으로 설계한다.

## 저장소 경계

`src/storage`에는 저장 방식에 종속되지 않는 타입과 인터페이스를 둔다. 예를 들어 저장·조회·삭제 동작의 계약만 정의하고, 실제 앱에서 필요한 저장 패키지를 선택해 구현한다. 템플릿 자체는 서버나 외부 DB를 호출하지 않는다.

## 쇼케이스 화면

`src/app/index.tsx`는 `template-showcase` 화면을 렌더링한다. 화면에는 제목·본문·보조 텍스트, 버튼, 카드, 입력 필드, 빈 상태, 구분선을 배치해 테마와 공통 UI를 한 번에 확인할 수 있게 한다. 새 앱을 시작할 때 이 화면은 삭제하거나 앱의 첫 화면으로 교체한다.

## 검증 기준

- 최신 안정 Expo SDK와 호환되는 의존성으로 설치된다.
- `expo-doctor` 진단에서 템플릿 자체의 의존성 오류가 없다.
- TypeScript 검사와 테스트가 통과한다.
- 쇼케이스 화면에서 모든 공통 UI가 흑백 토큰과 공통 간격을 사용한다.
- 템플릿 기본 설정에는 카메라·위치 등 기능별 권한이 없다.
- README만 보고 새 앱 레포를 만들고 이름·slug·패키지 식별자를 교체할 수 있다.

## 후속 운영

템플릿 검증이 끝나면 `minimalism-template` GitHub 레포지토리를 별도로 생성하고, 각 앱은 템플릿에서 복제해 독립 레포지토리로 운영한다.
